# Webowa Mapa Kawiarni – Projekt GIS
Aplikacja webowa prezentująca lokalizacje kawiarni na interaktywnej mapie. Projekt został wykonany w ramach zajęć **GIS – Systemy Informacji Przestrzennej**.


## Planowane Technologie
- **Frontend:** React.js, Next.js
- **Backend:** Node.js, Next.js
- **Baza danych:** MongoDB
- **Mapy:** Leaflet
- **Inne:** Git, Geocoding API 


## Opis projektu
Aplikacja umożliwia przeglądanie kawiarni na świecie oraz wyszukiwanie ich w określonych lokalizacjach. Każdy punkt na mapie zawiera podstawowe informacje o kawiarni, takie jak nazwa, typ (sieciowa/niezależna), opis i godziny otwarcia. System wykorzystuje geokodowanie do zamiany adresów na współrzędne oraz responsywny interfejs


## Funkcjonalności
- **Interaktywna mapa** z markerami kawiarni
- **Wyszukiwanie** kawiarni po wpisanej lokalizacji
- Szczegółowe informacje po kliknięciu markera
- **Integracja z bazą danych** MongoDB
- Automatyczne **geokodowanie** adresów
- Pełna **responsywność** interfejsu
